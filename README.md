# Hungry Car

An early browser build of Hungry Car. The embedded project includes a car, fish sprites, and mouse-driven game logic.

## Technologies

The repository contains a single HTML export generated with TurboWarp Packager. It embeds the Scratch project, assets and JavaScript player. Run the export in a modern browser with WebGL.

## Run locally

Clone the repository and open `index.html` in a modern browser. To serve it over HTTP, run:

```sh
git clone https://github.com/tanish1112/hungrycar.git
cd hungrycar
python3 -m http.server 8000
```

Open [localhost:8000](http://localhost:8000). Python is only needed for the optional local server.
